## 1. この文書について

### 1.1 目的

保守や機能追加のときに、画面・API・データベース・処理の決まりを、ソースコードを読まなくても確認できるようにします。

### 1.2 対象範囲

| 範囲 | 内容 |
| --- | --- |
| 公開サイト | トップページ、お問い合わせフォーム、LINE でのご相談、事業者情報（特定商取引法に基づく表記） |
| 管理画面 | お問い合わせの管理、見積書・入金（領収書）・保守契約、サイト内容・デザイン（色）・メールの設定、迷惑送信、履歴、データ管理、アカウント |
| API | FastAPI のバックエンド（公開サイト用・管理画面用） |
| データベース | SQLite（`data/app.db`） |
| スクリプト | 起動（`run_backend.sh`・`scripts/common.sh`）、API テスト（`tests/`） |

サーバーの構築手順は対象外です。本番で必要な条件だけを「[08 設定と運用](08_設定と運用.md)」に書いています。

### 1.3 書き方のきまり

- この設計書に書いた内容を「仕様」とします。今のコードと違うところは「[09 課題一覧](09_課題一覧.md)」に載せ、本文には「※課題 No.n」と書きます。
- 日時はデータベースに UTC（例: `2026-10-26T05:00:00Z`）で保存し、画面には日本時間で表示します。発行日・入金日などの「日付だけ」の項目は、日本時間の日付（`YYYY-MM-DD`）です。
- 金額は円の整数です。
- 図は Mermaid で書いています。GitHub と、Mermaid の拡張機能を入れた VS Code で図として表示されます。
- ブラウザで読むときは、同じフォルダの `README.html` を開きます。HTML は md から作ったものなので、md を直したら作り直します（図の表示にはインターネットへの接続が必要です）。
- ID は、公開サイトの画面が P-nn、管理画面の画面が A-nn、API が API-nn です。

## 3. 用語

| 用語 | 意味 |
| --- | --- |
| 公開サイト | お客さまが見るページ（トップページ・お問い合わせフォームなど） |
| 管理画面 | 管理者だけがログインして使うページ（`/admin` 以下） |
| 管理者 | 事業者本人。`.env` の `ADMIN_EMAIL` の1人だけ |
| お問い合わせ | お問い合わせフォームから届いた相談（`inquiries` 表） |
| 対応状況 | お問い合わせの状態。未対応・対応中・見積送付済み・契約済み・対応済み・お断り |
| 迷惑送信 | ブロックしたアドレスから届いたもの、または管理者が迷惑送信にしたお問い合わせ |
| ブロックリスト | 迷惑送信として扱うメールアドレス・ドメインの一覧（`blocklist` 表） |
| 隠し欄 | お問い合わせフォームの、人には見えない入力欄（ハニーポット）。値が入っていれば機械的な送信とみなす |
| 送信履歴 | 送るメールを1通ずつ記録したもの。送信の結果もここに残す（`mail_outbox` 表） |
| 新着通知 | お問い合わせが届いたことを管理者に知らせるメール |
| 自動返信 | お問い合わせを受け付けたことをお客さまに知らせるメール |
| 返信テンプレート | 管理画面からお客さまに返信するときに差し込む、件名と本文のひな形 |
| 差し込み項目 | `{name}` のように書くと、送るときにお名前などに置き換わる部分 |
| 保守契約 | 公開後のサーバー管理・修正をおまかせいただく月額の保守プランの契約 |
| サイト内容 | 管理画面から変えられる公開サイトの情報。事業者情報・料金の目安・よくある質問・制作実績・そのほかの制作物・お客さまの声 |
| テーマ色 | 公開サイトの基調色（1色）。管理画面の「デザイン（色）」で変える |
| 自動削除 | 対応が終わった古いお問い合わせ（個人情報）を、決めた期間のあとに削除する機能 |
| 操作の記録 | 管理画面で行った操作の記録（`audit_logs` 表） |
| デバイスコード | Outlook にサインインするときに、ブラウザで入力する短いコード（OAuth 2.0 のデバイス認可フロー） |
| マイグレーション | データベースの表・列を、起動時に順番に追加・変更するしくみ |
